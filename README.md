# Zvládnu to! – domácí AI učitelka

Hra pro Marečka: avatar Emička se ptá na obrázek, Mareček odpovídá ťuknutím nebo hlasem.

- **Kde je to?** – předložky a popis pokoje (na, pod, vedle)
- **Počítání** – počítání do 5 a sčítání
- **English** – první anglická slovíčka

Celá aplikace je jeden soubor `index.html`. Hlas: Web Speech API (čtení i rozpoznávání řeči v prohlížeči).
